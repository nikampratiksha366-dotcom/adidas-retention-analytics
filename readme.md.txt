# Adidas Customer Retention Analytics (Power BI)

## Overview
An interactive Power BI dashboard that analyzes customer churn, loyalty, and retention for Adidas using customer, transaction, store, and loyalty program data.

## Problem Statement
Adidas collects large volumes of customer data but lacks the analytical depth to understand why customers churn, identify loyal vs. at-risk customers, and measure the impact of loyalty tiers and promotions.

## Tools Used
- Power BI
- DAX
- Power Query

## Dashboard Pages
1. KPIs: Churn Rate, CLV, Repeat Rate
2. Loyalty and Promotion Impact
3. Store and Channel Insights
4. Customer Segmentation
