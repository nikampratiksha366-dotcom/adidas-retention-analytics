# Adidas Customer Retention Analytics

A Power BI dashboard designed to analyze customer churn, loyalty, and retention patterns for Adidas using customer, transaction, store, and loyalty data.

## Overview
This project helps identify:
- which customers are most at risk of churn
- how loyalty tiers and promotions influence retention
- which store types and regions need strategic attention
- how customer behavior varies across channels

The dashboard supports data-driven decision-making for customer retention strategy and marketing optimization.

## Business Problem
Adidas has access to large volumes of customer and transaction data, but lacks a clear, interactive view of:
- churn patterns by customer segment
- loyalty-tier performance and redemption behavior
- regional and channel-based retention differences
- the effectiveness of promotional campaigns

## Objectives
- Measure churn, repeat purchase behavior, and customer lifetime value (CLV)
- Identify at-risk customer segments
- Assess loyalty tier effectiveness
- Analyze campaign and promotion impact
- Understand store/channel and region performance

## Tools Used
- Microsoft Power BI
- DAX
- Power Query
- Excel / CSV data sources (if applicable)

## Dataset
The dashboard uses data from:
- customer information
- transaction history
- loyalty program data
- store and channel metadata
- sales and promotion details

This data enables analysis across customer segments, regions, store types, and loyalty tiers.

## Dashboard Pages
1. KPI Overview
   - Churn rate
   - Customer lifetime value
   - Repeat rate

2. Loyalty and Promotion Impact
   - loyalty tier performance
   - promo effectiveness
   - points redemption trends

3. Store and Channel Insights
   - channel comparison
   - store type performance
   - transaction value trends

4. Customer Segmentation
   - customer behavior by segment
   - retention risk analysis
   - tier-based insights

## Key Insights
- Elite tier customers show the highest churn rate (44.8%), while Base tier customers show the lowest churn rate (22.5%)
- Asia-Pacific has the highest churn rate among regions, while Europe and South America are comparatively lower
- Promotions were applied to 52.7% of transactions
- Promoted purchases generated higher average value compared to non-promoted purchases
- Online sales channels show the highest churn rate, while Franchise stores have the strongest average transaction value

## Recommendations
- Prioritize retention campaigns for Elite and Premium tier customers
- Improve customer experience and engagement in online channels
- Increase rewards redemption to improve loyalty outcomes
- Focus marketing efforts on high-risk customer groups and low-retention regions
- Use promotion strategies more selectively to maximize customer value and retention
